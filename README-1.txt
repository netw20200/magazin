MAGAZIN — Интернет-магазин цветов
================================

Описание
--------
Magazin — демонстрационный шаблон современного интернет-магазина цветов.
Проект создан на HTML, CSS и JavaScript без CMS и конструкторов.

Основные возможности
--------------------
- Каталог товаров из products.csv
- Поиск товаров по названию
- Сортировка по названию, категории и цене
- Отдельная страница товара
- Корзина с localStorage
- Счетчик товаров в корзине
- Оформление заказа
- Выбор способа доставки
- Отправка заказа через Telegram
- Адаптивный дизайн
- Боковое меню
- Кнопка возврата наверх
- SEO meta-теги
- Open Graph и Twitter Card
- Preview-изображение для социальных сетей
- Favicon и theme-color

Технологии
----------
HTML5
CSS3
JavaScript (Vanilla JS)
CSV
LocalStorage
Swiper
Material Symbols
GitHub Pages

Структура проекта
-----------------
index.html       — главная страница
product.html     — страница товара
cart.html        — корзина
checkout.html    — оформление заказа
contacts.html    — контакты
script.js        — основной JavaScript
product.js       — логика страницы товара
cart.js          — логика корзины
checkout.js      — оформление заказа
style.css        — основные стили
products.csv     — каталог товаров
images/          — изображения
preview.png      — Open Graph preview

products.csv
------------
Каталог товаров загружается из CSV-файла.

При изменении каталога необходимо сохранять структуру столбцов,
которую использует JavaScript.

Корзина
-------
Корзина сохраняется в браузере пользователя через localStorage.

Telegram
--------
Заказы отправляются через Telegram.
Перед публикацией необходимо заменить Telegram username
на аккаунт магазина.

Изображения
-----------
Изображения товаров находятся в папке images/.
Имя изображения в products.csv должно совпадать с именем файла
в папке images/.

Публикация
----------
Проект можно разместить на GitHub Pages или другом статическом хостинге.

Для GitHub Pages:
1. Загрузить файлы в репозиторий.
2. index.html должен находиться в корне проекта.
3. Включить GitHub Pages в настройках репозитория.
4. Дождаться публикации сайта.

SEO
---
В проекте предусмотрены:
- title
- meta description
- robots
- canonical
- Open Graph
- Twitter Card
- favicon
- theme-color

Для каждой страницы рекомендуется использовать уникальные
title и description.

Open Graph
----------
Для превью ссылки используется preview.png.
Рекомендуемый размер: 1200 × 630 px.

Перед публикацией нужно проверить, что og:image указывает
на доступный полный URL изображения.

Перед продажей
--------------
Перед передачей проекта клиенту рекомендуется:
- заменить контактные данные;
- заменить Telegram username;
- заменить адрес и график работы;
- заменить товары в products.csv;
- заменить изображения;
- проверить ссылки меню;
- проверить поиск и сортировку;
- проверить корзину;
- проверить оформление заказа;
- проверить мобильную версию;
- проверить SEO и Open Graph.
